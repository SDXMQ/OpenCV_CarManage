AI 감정 분석 기반 스마트 차량 시스템 (SEAVS) - 개발 설계서
================================================================================

1. 개발 환경 격리 (1번 이슈: venv 가상환경)
--------------------------------------------------------------------------------
로컬 PC 패키지 오염 및 버전 충돌을 방지하기 위해 venv를 기반으로 샌드박스를 구축합니다.

* 가상환경 구축 명령어:
  ```powershell
  # 1. 가상환경 생성
  python -m venv venv

  # 2. 가상환경 활성화 (Windows PowerShell 기준)
  .\venv\Scripts\Activate

  # 3. 필수 패키지 설치
  pip install opencv-python mediapipe deepface flask flask-socketio paho-mqtt
  ```

* 주요 라이브러리 선정 이유:
  - opencv-python: 웹캠 영상 프레임 캡처 및 이미지 처리/인코딩.
  - mediapipe: 실시간으로 얼굴 특징점(468 landmarks)을 빠르게 추출하여 눈 깜박임(EAR)을 통한 졸음 감지 구현.
  - deepface: 자체 모델 빌드 없이 실시간 감정(Angry, Fear, Happy, Sad, Neutral)을 분석하는 경량 래퍼 라이브러리.
  - flask & flask-socketio: 웹 샌드박스 대시보드 제공 및 카메라 프레임, 실시간 센서 데이터 브라우저 송출.
  - paho-mqtt: 차량 데이터(속도, 브레이크 등)를 퍼블리싱/서브스크립션하는 통신 라이브러리.


2. 웹 샌드박스 및 실시간 스트리밍 설계 (3번 이슈: Browser Streaming)
--------------------------------------------------------------------------------
cv2.imshow() 대신 웹 브라우저를 최종 GUI로 사용합니다. 이 구조는 OpenCV GUI 관련 디스플레이 스레드 에러를 방지하고, 웹 UI로 유연한 디자인을 구성할 수 있게 합니다.

■ 전체 데이터 흐름:
[로컬 웹캠] 
     ↓ (cv2.VideoCapture)
[AI 분석 모듈 (Mediapipe + DeepFace)] 
     ↓ 1) 가공된 프레임 (얼굴 바운딩 박스 & 랜드마크 렌더링)
     ↓ 2) 감정 데이터 (Angry, Drowsy, Stressed, Normal 지수)
[Flask 백엔드]
     ├─▶ MJPEG 비디오 피드 제공 (/video_feed 라우트) ──▶ 브라우저 <img src="/video_feed">
     └─▶ 감정/차량 센서 JSON 데이터 송신 (Socket.IO) ──▶ 브라우저 대시보드 (Chart.js 등)

■ 핵심 구현 설계:
* A. 비디오 스트리밍 설계 (Multipart HTTP Response)
  - OpenCV로 캡처한 프레임을 JPEG로 인코딩한 뒤, Flask generator 함수를 통해 `multipart/x-mixed-replace` 컨텐트 타입으로 스트리밍합니다.
  - 이 방식은 HTML에서 단순 <img> 태그 하나로 프레임 드랍 없이 실시간 영상을 수신할 수 있게 합니다.

* B. 양방향 실시간 제어 설계 (Socket.IO)
  - 감정 상태가 바뀔 때(예: Neutral -> Angry)나 가상 차량 데이터(속도, 브레이크)가 들어올 때, Socket.IO 이벤트를 브라우저로 실시간 브로드캐스트합니다.
  - 브라우저는 이를 받아 실시간 그래프(차량 속도 및 감정 지수)를 갱신하고 배경 조명 테마 색상을 변경합니다.

4. 핵심 AI / 알고리즘 설계
--------------------------------------------------------------------------------
* 눈 감김 감지 (졸음 감지):
  - Mediapipe Face Mesh를 사용해 양쪽 눈 주변 특징점 좌표 6개씩 추출.
  - EAR(Eye Aspect Ratio) 수식 적용:
    EAR = (|p2 - p6| + |p3 - p5|) / (2 * |p1 - p4|)
  - EAR 임계값(약 0.2~0.25) 이하가 3초 이상 지속될 시 졸음(Drowsy)으로 판정.

* 감정 감지:
  - DeepFace의 `analyze(img, actions=['emotion'], enforce_detection=false)` 함수를 일정 주기(예: 0.5초 또는 1초 간격)마다 백그라운드 스레드에서 호출하여 연산 부하를 최소화.
  - 가장 지배적인 감정(dominant_emotion)을 추출하여 대시보드로 전송.


5. 차량 데이터 & 감정 시나리오 연동
--------------------------------------------------------------------------------
* MQTT 토픽 설계:
  - `car/sensors`: 차량 운행 데이터 (속도, 브레이크 압력, 급가속 여부) -> JSON 포맷
  - `car/driver/emotion`: 분석된 감정 상태 -> JSON 포맷

* 복합 이벤트 처리 로직 (Flask 서버 측):
  - 만약 감정 상태 == 'Angry' 이고, 차량 센서 데이터 중 'rapid_acceleration' == true 이면:
    -> 대시보드에 빨간색 경고 사이렌 애니메이션 작동 및 경고 메시지 송출.
    -> 백엔드에서 차량 오디오 제어 시뮬레이션을 통해 잔잔한 음악 재생.
  - 만약 졸음(Drowsy) 상태 == true 이면:
    -> 대시보드 경고음 발생 및 조명 제어 테마를 노란색 점멸로 전환.
