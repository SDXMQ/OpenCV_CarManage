# 🚗 SEAVS: Smart Emotion-Aware Vehicle System
> **AI 감정 분석 및 졸음 감지 기술 기반 스마트 차량 콕핏 대시보드 시뮬레이터**

## 🌟 주요 기능 (Key Features)

* **🧠 실시간 AI 감정 분석 (Emotion Detection)**
  - ONNX 기반의 **FER+ 모델**(`emotion_ferplus.onnx`)을 활용하여 운전자의 감정을 실시간으로 분석합니다.
  - 감정 카테고리: `Angry`(분노), `Happy`(기쁨), `Sad`(슬픔), `Neutral`(평온), `Surprise`(놀람), `Disgust`(불쾌), `Fear`(공포)
  - 지배적인 감정(Dominant Emotion) 분석 및 상위 3개 감정 확률 점수 실시간 차트 제공.

* **👁️ 정밀 졸음 감지 (Drowsiness Detection)**
  - **MediaPipe Face Mesh (468 Landmarks)** 기술을 탑재하여 운전자의 양쪽 눈 특징점을 실시간으로 추출합니다.
  - 눈 깜박임 비율인 **EAR(Eye Aspect Ratio)** 수식을 계산하여 운전자의 졸음 여부를 지속적으로 진단합니다.
  - 운전자가 설정 임계값 이하로 3초 이상 눈을 감고 있을 경우 졸음(`Drowsy`) 상태로 판정하고 즉각적인 안전 인터락을 가동합니다.

* **🔌 가상 CAN 버스 네트워크 구성 (`python-can` 연동)**
  - 내부의 직접적인 함수 호출 대신, 실제 차량 네트워크 구조를 모사하여 **가상 CAN 메시지 기반의 비동기 통신**을 구현했습니다.
  - 운전자 상태정보(`0x110`), 생체 수치 데이터(`0x120`), AI 기반 다감각 공조 제어 명령(`0x210`) 등을 8바이트 표준 프레임 패킷으로 가공해 가상 CAN 채널로 송수신합니다.

* **📡 IoT 디지털 트윈 및 실시간 차량 관제 (MQTT)**
  - 시뮬레이터 구동 시 가상의 차량 고유 ID(예: `SEAVS-EV-1234`)를 자동으로 부여하고, 차량의 배터리, 속도, 공조 소비전력, CO2, 감정 수치 등을 백그라운드 스레드에서 공용 MQTT 브로커(`broker.hivemq.com`)로 전송합니다.
  - **독립적인 관제 모니터 대시보드**: 별도의 GUI 모니터(`fleet_monitor.py`)를 통해 클라우드 브로커로부터 수신받은 실시간 차량 원격 측정 데이터(Telemetry)를 차트와 리스트 형태로 모니터링합니다.

* **🔋 가상 배터리 물리 모델 및 다목적 공조 최적화 솔버**
  - 냉방(압축기), 난방(PTC 히터), 송풍 작동 여부에 따른 가상 차량의 실시간 배터리(SOC) 소비 물리 모델을 `vehicle_env.py`에 구축했습니다.
  - 졸음/경고 상태 진입 시, **배터리 잔량(SOC)에 따라 목적 함수 가중치($w_1, w_2$)를 실시간으로 자동 산출**하여 운전자 각성 유지 성능과 배터리 절약 성능의 완벽한 균형을 도출하는 그리드 서치(Grid Search) 최적화 솔버를 구현했습니다.

* **📊 프리미엄 어두운 테마 UI 대시보드 (Premium Cockpit GUI)**
  - **CustomTkinter**를 사용하여 세련된 다크 모드 기반 스마트 콕핏 디자인을 구현하였습니다.
  - **실시간 비디오 피드**: 운전자의 얼굴 바운딩 박스 및 특징 랜드마크가 시각화되어 출력됩니다. 비디오 스케일링 성능을 개선(`Image.BILINEAR` 적용)하여 화면 크기 변경 시 렉이나 프레임 드랍을 차단했습니다.
  - **레이아웃 컴팩트화**: 설정 시뮬레이터와 배터리 현황판을 탭뷰 스택(`🔋 Battery`, `🌍 Environment` 탭)으로 묶고, 에어컨 패널 배치 우선순위를 고정하여 저해상도 모니터 및 윈도우 배율 환경에서도 공조 조작계가 잘림 없이 항상 노출되도록 보장했습니다.
  - **에어컨 애니메이션**: 바람세기 및 냉방 상태에 따라 반응형 바람 그래픽 및 팬 애니메이션 효과가 가동됩니다.

## 🛠️ 기술 스택 (Tech Stack)

* **언어:** `Python 3.10+`
* **UI 프레임워크:** `CustomTkinter`, `Pillow`
* **인공지능 및 컴퓨터 비전:** `OpenCV (opencv-python)` (ONNX 모델 추론용 DNN 모듈), `MediaPipe`
* **유틸리티 및 하드웨어 통신 연동용 프로토콜:** `python-can` (가상 CAN 버스 네트워크 레이어), `paho-mqtt` (IoT 텔레메트리 클라이언트), `pygrabber` (카메라 장치 자동 검색)

## 🚀 시작하기 (How to Run)

본 프로젝트는 Windows 환경에서 가상환경(`venv`) 생성, 의존성 패키지 설치 및 두 대시보드 창의 실행까지 자동으로 구동하는 원클릭 배치 스크립트를 제공합니다.

### 1. 요구사항
* 웹캠(Webcam)이 연결된 PC
* Python 3.10 이상 설치 필수 (환경 변수 PATH 등록 권장)
* (선택) 인터넷 네트워크 연결 (HiveMQ 공개 MQTT 브로커를 통한 텔레메트리 연동용)

### 2. 실행 방법
프로젝트 루트 디렉토리에서 **`run.bat`** 파일을 실행(더블 클릭)합니다.
```bash
# 또는 터미널(Command Prompt / PowerShell)에서 직접 실행
./run.bat
```
* **동작 과정:**
  1. 루트 디렉토리에 가상환경(`venv`)이 없는 경우 자동으로 생성합니다.
  2. 가상환경을 활성화하고 `requirements.txt`에 명시된 필수 패키지들(`python-can`, `paho-mqtt` 등)을 무음 설치합니다.
  3. 스마트 차량 콕핏 시뮬레이터(`src/main.py`)와 IoT 관제 모니터 대시보드(`fleet_monitor.py`)를 각각 개별 프로세스로 동시에 자동 구동합니다.

| 상황 (Driver State) | 시스템 진단 (Safety Evaluation) | 차량 대응 제어 (Vehicle Action - AI 자동 모드 시) |
| :--- | :--- | :--- |
| **평온 (Neutral)** | 😊 안전 운전 상태 유지 | 표준 설정 유지 (22°C, 일반 공조) |
